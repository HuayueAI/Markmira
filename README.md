## ✨ Features

| | |
|---|---|
| 🖊 **WYSIWYG Editing** | A seamless editing experience without switching between Markdown source and preview. |

| ✨ **AI Revision** | Let AI refine, rewrite, and polish your writing while staying in control of every change. |

## 🧩 Plugins

Markmira ships as a lightweight core. Browse the built-in plugin market inside the app to install only what you need — plugins are downloaded, updated and removed without leaving the app.

Official plugins are distributed from the [markmira-plugin-releases](https://github.com/HuayueAI/markmira-plugin-releases) repository and include:

- **AI Assistant** — chat with any OpenAI-compatible provider using your own endpoint, API key and model
- **Draw.io** — embedded diagram editor
- **Excalidraw** — hand-drawn style whiteboarding
- **PDF Viewer** — read and annotate PDF documents
- **Text Editor** — plain text editing

## 简体中文

**尽管书写，即刻呈现。**

Markmira 是一款本地优先、支持插件的桌面写作与文档工作空间。从干净的所见即所得 Markdown 编辑器开始，把它打造成属于你的工作空间。

### 特性

- 🖊 **所见即所得** —— 无需在 Markdown 源码和预览之间切换，享受流畅自然的编辑体验。
- 🗂 **多格式工作空间** —— 在同一个工作空间中处理 Markdown、PDF、电子表格等多种文档。
- ✨ **AI 修订** —— 让 AI 帮你优化、改写和润色，每一处修改都由你掌控。
- 💾 **本地优先** —— 以便于迁移的开放格式，将文档保存在你自己的设备上。
- 🧩 **插件生态** —— 从轻量的编辑器开始，按需扩展：绘图、PDF 阅读、AI 助手等。
